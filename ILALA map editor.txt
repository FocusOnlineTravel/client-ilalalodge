  - View & Zoom: Fit / 50% / 100% zoom with drag-to-pan                                                                                                                         
  - Add markers: Click "+ Hotel" or "+ POI" then click on the map                                                                                                               
  - Edit markers: Click any marker to edit title, blurb, icon, color, position                                                                                                  
  - Drag to reposition: Click and drag any marker to move it                                                                                                                    
  - Delete markers: Delete button in edit panel                                                                                                                                 
  - Export JSON: Copies the markers array to clipboard - paste directly into code                                                                                               
                                                                                                                                                                                
  How to use:                                                                                                                                                                   
  1. Go to http://localhost:3001/map-editor                                                                                                                                     
  2. Click "+ POI" to add a new point of interest                                                                                                                               
  3. Click on the map to place it                                                                                                                                               
  4. Fill in title, description, choose icon and color                                                                                                                          
  5. Save                                                                                                                                                                       
  6. Repeat for all markers                                                                                                                                                     
  7. Click "Export JSON" when done                                                                                                                                              
  8. Paste the JSON into InteractiveMap.tsx replacing the markers array
